How to use the tracker
  1. Use wired headphones. Start audio, then permit autoplay if the browser asks.
  2. Face the Mac and click Set forward. Keep still for two seconds. Mirror display + audio mirrors the preview and the headphone left/right. World stays a room view from behind you.
  3. Plug in the Arduino saber and keep shoulders and the holding hand in frame. Point the blade toward the camera, click Set saber reference, and keep still for two seconds. Calibrate the sensors once with the wires fixed: hold still, pause on each of the six faces, then tumble slowly away from metal.
  4. To use an iPhone instead, start with ./run.zsh --iphone. In ZIG SIM enable GYRO, QUATERNION, and GRAVITY.
